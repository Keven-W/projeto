## 🌦️ Projeto Acadêmico – As Estações do Ano

Este projeto foi desenvolvido como parte de um **trabalho acadêmico da faculdade**, com o objetivo de apresentar de forma visual e interativa as **quatro estações do ano**: primavera, verão, outono e inverno.

A proposta foi criar uma página web que combinasse **conteúdo informativo com elementos visuais dinâmicos**, permitindo que o usuário compreenda melhor as características de cada estação por meio de **animações e efeitos de interface**.

### 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando apenas as **tecnologias fundamentais da web**, sem o uso de frameworks ou bibliotecas externas:

* **HTML** – responsável pela estrutura e organização do conteúdo da página
* **CSS** – utilizado para o design, cores, layout e estilização dos elementos
* **JavaScript** – aplicado para criar **animações, interações e efeitos visuais**, tornando a navegação mais dinâmica e envolvente

### 🎯 Objetivo do Projeto

Além de apresentar informações sobre as estações do ano, o principal objetivo deste trabalho foi **praticar os fundamentos do desenvolvimento web**, explorando como **HTML, CSS e JavaScript podem trabalhar juntos** para criar experiências interativas.

Todo o desenvolvimento foi realizado utilizando **JavaScript puro (Vanilla JS)**, sem frameworks como React ou bibliotecas externas, com foco no aprendizado dos conceitos básicos de **manipulação do DOM, eventos e animações na interface**.

---

✨ Este projeto representa um exercício prático de aprendizado e evolução no desenvolvimento front-end, demonstrando a aplicação dos conceitos fundamentais da web na criação de interfaces simples, funcionais e interativas.
